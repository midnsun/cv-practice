# Библиотека и консольный скрипт фильтров изображений
Python-библиотека и консольная утилита для обработки изображений с использованием 'NumPy' и 'PIL'
Содержит набор из 8 фильтров с параметрами

---

## Инструкция по использованию

Для работы библиотеки требуется **Python 3.8+**. Основные вычисления и операции над матрицами выполняются с помощью библиотеки **NumPy**.

### Установка зависимостей

Установите необходимые пакеты с помощью `pip`:

```bash
pip install numpy pillow
```

> **Прмечание**: `Pillow` используется только для сохранения файлов и не используется при обработке в фильтрах.

### Инструкция по запуску

Скрипт запускается через командную строку:

```bash
python ImageProcessing.py --input <путь_к_входному_файлу> --output <путь_к_выходному_файлу> --filter <название_фильтра> [аргументы]
```

Поддерживаются относительные и абсолютные пути (используя флаг `--absolute`). Относительные пути вычисляются от вложенной в проект папки `img`.

## Структура проекта

Проект находится в папке ZagriadskovMA/1_ImageProcessing. В ней содержатся файлы модулей, папка img с входными и выходными изображениями, к которой обращаются относительные пути, а также этот файл `README.md`. Файлы модулей содержат следующие функции:
1. `cli_parser.py` - файл с функцией парсинга аргументов
2. `image_io.py` - файл с функций ручного чтения изображения и записи изображения через `PIL`
3. `my_filters.py` - файл с абстрактным классом фильтром и реализацией всех фильтров
4. `ImageProcessing.py` - главный файл, содержит функцию `main` и вызывает нужные функции из других модулей

## Описание математических алгоритмов и фильтров

### Алгоритм чтения PNG файла и конвертация в матрицу интенсивности

1. Проверка первых 8 байт на соответствие Magic Number `\x89PNG\r\n\x1a\n`
2. Распаковка заголовков чанков, формат хранения Big-Endian
    1. В заголовочном чанке хранится информация о размере изображения, глубина и тип цвета, компрессия и чресстрочный интервал
    2. В чанке данных хранятся сжатые данные, собираем в один список
    3. Конечный чанк обозначает конец файла
3. Выделяем данные для изображения в соответствии с размером кодирования цвета
4. Разархивируем список чанков с `ZIP (Deflate)`
5. Применяем обратные фильтры к распакованным данным:
    1. Тип фильтра 0 - без фильтра
    2. Тип фильтра 1 - сумма с левым пикселем
    3. Тип фильтра 2 - сумма с верхним пикселем
    4. Тип фильтра 3 - сумма со средним значением левого и верхнего пикселя
    5. Тип фильтра 4 - сумма со значением предиктора Паэта от левого, верхнего и лево-верхнего пикселей
6. Сохраняем результат в матрицу `NumPy`

### Алгоритм изменения размера Resize

1. **Использование**:
```bash
python .\ImageProcessing.py -i test_image.png -o test_resize.png -f resize --params width=1020 height=768
```
Принимает обязательные параметры ширины и высоты изображения.

2. **Алгоритм**:\
Используется **билинейная интерполяция**. Векторизованно каждый пиксель итогового изображения вычисляется как среднее между 4-мя пикселями исходного изображения, соседними с образом точки результирующего изображения. Причём, сначала выполняется интерполяция по `x`, а затем по `y`.

### Алгоритм перевода изображения в оттенци серого

1. **Использование**:
```bash
python .\ImageProcessing.py -i test_image.png -o test_grayscale.png -f grayscale
```
Не принимает параметров

2. **Алгоритм**:\
В соответствии с телевизионным стандартом [ITU-R Rec. 709](https://en.wikipedia.org/wiki/Rec._709), каждый пиксель по 3 цветам векторизованно переводится в его интенсивность по формуле: 
`Intencity = 0.2126*R + 0.7152*G + 0.0722*B`

### Фильтр "Антиквариат"

1. **Использование**:
```bash
python .\ImageProcessing.py -i test_image.png -o test_antique.png -f antique --params intensity=0.7
```
Принимает параметр интенсивности применения фильтра, по умолчанию равен `0.7`. Диапазон от 0 до 1.

2. **Алгоритм**:\
Векторизованно применяет к каждому вектору интенсивности цветов матрицу Сепии. В результате красный канал усиливается, синий канал ослабляется, зеленый получается смешиванием цветов:

`R' = 0.393*R + 0.769*B, 0.189*G`\
`G' = 0.393*R + 0.769*B, 0.189*G`\
`B' = 0.272*R + 0.534*B + 0.131*G`

После применения Сепии полученное изображение смешивается с исходным с параметром интенсивности.

### Фильтр выцветания

1. **Использование:**
```bash
python .\ImageProcessing.py -i test_image.png -o test_fadecolor.png -f fadecolor --params max_fade=50.0
```
Принимает опциональный параметр `max_fade`, отвечающий за сжатие цветового диапазона (отступ от максимальной и минимальной) интенсивности. По умолчанию равен `50`. Диапазон от 0 до 255.

2. **Алгоритм:**\
Вычисляет множитель, на который сокращается динамический диапазон, после чего по формуле `result = min + image * scale` векторизованно вычисляет новый цвет.

### Имитация пленки

1. **Использование:**
```bash
python .\ImageProcessing.py -i test_image.png -o test_fadecolor.png -f tape --params mode=infraded grain_amount=0.3
```
Принимает опциональные параметры `mode` (значения `infraded` и `classic`) - тип пленки и `grain_amount` (значения от 0 до 1) - величину пленочного зерна. Значения параметром по умолчанию `infraded` и 0.3 соответственно.

2. **Алгоритм:**\
Применяет матрицы инфракрасной или винтажной пленки к цветам пикселей. Ниже приведены вычисления для инфракрасного фильтра:

`R' = 0.1*R + 1.5*B, -0.2*G`\
`G' = 0.6*R + 0.2*B, 0.1*G`\
`B' = -0.1*R + 0.1*B + 0.8*G`

Красный цвет чувствителен к зелёному, поскольку листва излучает инфракрасный свет и краснеет. Синий цвет (вода и небо) уводится в темные тона, так как поглощает инфракрасный свет. Зелёный канал приглушается.\
После вычсления цветов при помощи нормального распределения генерируется пленочное зерно, которое может сделать пиксель темнее или светлее. Оно применяется совместно с параболическим фильтром, делающим зернистый эффект виднее в полутонах (при интенсивности 0.5) и почти незаметным на ярких/темных участках.

### Наложение овальной маски (Matte)

1. **Использование:**
```bash
python .\ImageProcessing.py -i test_image.png -o test_matte.png -f matte --params scale=0.9 feather=0.15 fill_color=255 255 255
```
Принимает опциональные параметры `scale` (от 0.1 до 1, по умолчанию 0.9) - отступ от границы изображения, `feather` (значения от 0.001 до 0.5, по умолчанию 0.15) - "плавность" фильтра и `fill_color` (кортеж RGB, по умолчанию белый) - цвет заливки овала.

2. **Алгоритм:**\
Считает эллипс с полуосями, равными половине высоты и ширины изображения, помноженными на `scale`. Вне эллипса, а также на границe `+-feather` заполняет изображение цветом `fill_color` по правилу интерполяции `3t^2+2t^3`.

### Состаривание фотографии

1. **Использование:**
```bash
python .\ImageProcessing.py -i test_image.png -o test_noize.png -f noize --params noize_amount=0.008 num_scratches=12, scratch_intensity=0.7
```
Принимает опциональные параметры `noize_amount` (от 0 до 0.1 по умолчанию 0.008) - количество шума, `num_scratches` (> 0, по умолчанию 12) - количество царапин на изображении и `scratch_intensity` (от 0 до 1) - интенсивность царапин.

2. **Алгоритм:**
    1. Генерирует случайный равномерный шум по изображению, светлый и темный
    2. Генеририрует случайные точки на изображении, между которыми проводит линию царапины. С вероятностью 0.8 предпочтение отдается вертикальным царапинам, симулируя эффект прокатной машины
    3. Линии проводятся по упрощенному алгоритму Брезенхема. Ширина линий переменная, подчиняется нормальному распределению. При этом, удаляясь от математической прямой, её яркость затухает.
    4. Царапины смешиваются с итоговым изображением с параметром интенсивности `scratch_intensity`.

### Неоновое свечение

1. **Использование:**
```bash
ython .\ImageProcessing.py -i test_image.png -o test_neon.png -f neon --params glow_color=0 255 230 intensity = 1.5 blur_radius=2
```
Принимает опциональные параметры `glow_color` (кортеж RGB, по умолчанию (0, 255, 230)) - неоновый цвет, `intensity` (по умолчанию 1.5) - порог окраски границ и `blur_radius` (> 1, по умолчанию 2) - радиус заполнения неоновых границ.

2. **Алгоритм:**
    1. Строит матрицу интенсивности (как в фильтре grayscale)
    2. К ч/б изображению применяется оператор Собеля для выделения границ: на основе величины градиента изменения интенсивности строится маска границ объектов
    3. К маске границ применяется эффект размытия после чего они закрашиваются цветом `glow_color`
    4. Итоговое изображение складывается из затемнённого на некоторый параметр исходного изображения и неоновых границ с размытием
